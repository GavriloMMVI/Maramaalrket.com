Complete Full-Stack Deployment & Runbook

Step-by-step instructions to take this architecture into full live production on Vercel + Neon/Supabase PostgreSQL + Safaricom Daraja + Cloudinary.

1

PostgreSQL & Prisma Migration

Provision a managed PostgreSQL instance on Neon.tech or Supabase. Then push the schema and execute the secure admin seed:

# Install dependencies

pnpm install

# Run migrations to Neon/Supabase

pnpx prisma migrate dev --name init

# Seed initial admin user securely

pnpx prisma db seed

2

Configure Production .env

Populate environment variables in Vercel Project Settings. Note that admin credentials are never bundled into client JS:

DATABASE_URL="postgres://..."

NEXTAUTH_SECRET="32-byte-hex..."

ADMIN_INIT_EMAIL="admin@maramarket.co.ke"

ADMIN_INIT_PASSWORD="StrongSecurePassword!"

MPESA_CONSUMER_KEY="..."

MPESA_PASSKEY="..."

3

Vercel Build & Daraja Webhook

Deploy your GitHub repository directly to Vercel and register the Daraja STK Push callback URL:

# Build verification

pnpm run build

# Webhook Target URL

https://maramarket.vercel.app/api/mpesa/callback

# Cloudinary Upload Preset

CLOUDINARY_PRESET="maramarket_unsigned"

Production Architecture Checklist & Security Guarantees

Zero Client-Side Admin Elevation

Roles are stored solely in the PostgreSQL database and signed into HttpOnly session JWTs. Next.js middleware and Server Actions verify `token.role === 'ADMIN'` on every single request. No client-side JavaScript manipulation can bypass the database filter.

Safaricom Daraja 2.0 Idempotency

The STK Push webhook verifies `MerchantRequestID` & `CheckoutRequestID` against existing transaction records, executing an ACID Prisma transaction to boost the listing and log the transaction receipt instantly.

Direct Cloudinary Storage

Images are processed with signed / verified uploads directly to Cloudinary CDN, storing only optimized HTTPS asset URLs and public IDs in the PostgreSQL `Listing.images` array.

Moderation & Anti-Spam Pipeline

New listings default to `PENDING` or `APPROVED` based on seller student verification score. Campus members can flag suspicious listings, alerting the admin with direct 1-click ban and takedown capabilities.
